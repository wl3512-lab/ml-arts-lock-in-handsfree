ML Arts final proposal · Lucy Liu

lock in,
hands-free

My study timer starts when I sit down, pauses when I walk away, and dims when I pick up my phone.

what I have

lock in: the timer I use every day

A menu bar study timer: focus and break rounds, themes, background sounds, share codes so friends study on the same clock. Started from Braxton Hauw's web timer.

It works. But it only knows what I tell it.

the problem

Three things I have to remember

press start

Starting is the hardest part of studying. The button is one more thing between me and starting.

press pause

I forget when I get up, so "50 min of focus" includes the kitchen.

put the phone down

The timer has no idea I've been scrolling for ten minutes.

the rule

The machine learning may only remove a step. Never add one.

No typing what I'm studying. No rating sessions. No new screens.

what it does

Sit down · 5 s, then "starting…" you can cancel

Walk away · 10 s, pauses and takes those seconds back

Phone · 20 s, ring dims quietly, never pauses

the ML

A model trained on my own desk

  • Teachable Machine (week 2): 3 classes, working / phone / away, about 50 photos each.
  • Why not pretrained? bodyPose sees "a person" whether I'm working or scrolling. It knows away vs here, not phone vs work.
  • The test: run both side by side for a day and count mistakes. That's my answer to "train your own vs pretrained", with my own numbers.
  • Ignore anything under 70% confidence. A label has to hold for a few seconds before anything happens.
designing for when it's wrong
wrong pause

One tap, "I was here": it resumes and gives every second back. Each fix gets counted.

shared sessions

Pausing changes the share code today, so in a shared session it only tracks my away time.

camera trust

Off by default. A small eye when it's on. Frames are never saved or sent anywhere.

audience + plan

Me first, then 3 friends

  • 11/13–11/20 · train on my desk, day and night, compare against bodyPose
  • 11/20–11/27 · build it into the lock in web timer, keep share codes working
  • 11/27–12/4 · 3 friends use it, tune timings from what they fix by hand
